# 运营手册（给创始人自己看）

你是这个平台的「调控者」。下面是你每天、每周要做的事，以及出问题时怎么办。**你不需要写代码**，所有操作要么点按钮，要么在 Claude 里说一句话。

## 每天（约 10 分钟）

| 时间 | 谁做 | 做什么 |
|---|---|---|
| 08:00 | GitHub 自动 | 抓取官方招聘页、YC、HN、实习僧、电鸭 → 分类 → 更新网站 |
| 09:00 | Claude 定时任务 | 在你的 Chrome 里巡检 Boss、LinkedIn、X、JobsDB、即刻、牛客、Wellfound、脉脉、小红书 |
| 09:00 之后 | **你** | 在 Claude 对话里看候选清单，回复「收录 1、3、5」或「全部收录」 |
| 随时 | **你** | 刷到好岗位 → 网站右上角「＋ 提交岗位」→ 去 GitHub 给这个 Issue 加 `approved` 标签 |

## 每周（约 20 分钟）

1. 打开网站「本周变动」，看看有没有下线得特别多的公司（可能是招聘页改版）。
2. 打开仓库里的 `data/funding_leads.json`（或直接让 Claude 读），看本周新融资的 AI 公司，挑值得关注的加入公司库：
   对 Claude 说：「把 XX 公司加进 companies.yaml，查一下融资来源和它用的招聘系统」。
3. 给丙档公司补融资来源：对 Claude 说「帮我核实丙档公司的融资，有公开来源的升到甲档」。

## 常用指令（直接对 Claude 说）

- 「今天的巡检候选给我看一下」
- 「加一个关键词：AI 出海 KOL 实习，Boss 和小红书都要搜」 → 改 `config/sources.yaml`
- 「XX 公司不要了，加入排除名单，原因是……」 → 改 `data/companies.yaml` 的 `blocked`
- 「这个岗位其实不能远程，帮我改掉」 → 改 `data/manual_jobs.yaml`
- 「网站上 XX 显示不对」 / 「GitHub 上有一个 health Issue，帮我修」

## 出问题时

- **GitHub 开了一个「⚠️ 每日抓取有渠道出错」的 Issue**：把链接发给 Claude，说「帮我修」。
- **Chrome 巡检遇到验证码**：它会自动停下并告诉你。你手动在 Chrome 里完成验证即可，第二天会继续。不要让它绕过。
- **网站没更新**：打开仓库的 Actions 页，看「每日更新」是不是红色。可以点「Run workflow」手动重跑。

## 文件说明（只需要知道这几个）

| 文件 | 作用 |
|---|---|
| `config/criteria.yaml` | 筛选规则：什么算实习、什么算技术岗、远程/签证怎么判断 |
| `config/sources.yaml` | 渠道开关和关键词 |
| `data/companies.yaml` | 公司库：融资、档位、招聘系统、排除名单 |
| `data/manual_jobs.yaml` | 人工收录的岗位（巡检、投稿、种子） |
| `data/jobs.json` | 网站读取的最终数据（自动生成，不要手改） |
| `patrol/PATROL.md` | Chrome 巡检的规则 |
